Sobre mim

Sou graduando em Engenharia de Software pela UFMS, atualmente no 5º semestre, com experiência prática em desenvolvimento e suporte a sistemas. Atualmente atuo como estagiário de Suporte de TI na Cruzeiro do Sul Transportes, onde tenho aplicado conhecimentos em Java, Python, HTML, CSS, JavaScript e SQL, sempre utilizando Git e trabalhando com metodologias Scrum.
Minha trajetória combina aprendizado acadêmico e aplicação real:
👨‍💻 Desenvolvimento back‑end em Java, com foco em criação de APIs REST, integração com banco SQL Server e lógica bem estruturada.
🐍 Projetos pessoais em Python, lidando com dados, scripts automatizados e lógica aplicada.
🌐 Conhecimento em front‑end básico (HTML/CSS/JavaScript) para integrar interfaces web com back‑end.
☁️ Experiência inicial com git para versionamento e colaboração em equipe usando Scrum em projetos acadêmicos ou colaborativos.
Sou motivado por resolver problemas com código e estou dedicado a evoluir para uma carreira como desenvolvedor back‑end Java, construindo aplicações escaláveis e performáticas. Tenho projetos próprios (com leitura de dados via SQL, APIs em Java, versionamento com Git) disponíveis no GitHub.
Estou aberto a conectar com profissionais da área—seja para trocar insights, mentoria ou oportunidades de estágio e desenvolvimento.
